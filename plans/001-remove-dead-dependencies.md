## Why this matters

The shadcn/ui scaffold (`components/ui/`, 50 files) was deleted in PR #7, but
its entire dependency surface stayed behind in `package.json`: 27 `@radix-ui/*`
packages plus 15 companions. **None of them is imported anywhere in the source
tree** (verified by grep at planning time). They slow `pnpm install`, inflate
`pnpm audit` with noise from transitive packages (lodash via recharts, etc.),
and make the repo docs lie: `CLAUDE.md` §7 claims "the leanest dep tree this
project has ever had". This repo has an established pattern of dedicated
dep-removal PRs (PR #6, #11, #20 — see gotcha `dead-deps-removal-dedicated-pr`
in `.claude/knowledge/gotchas.yaml`): this plan is the fourth wave.

  `react`, `react-dom`.

## Commands you will need

| Purpose   | Command                     | Expected on success |
|-----------|-----------------------------|---------------------|
| Install   | `pnpm install`              | exit 0              |
| Typecheck | `pnpm exec tsc --noEmit`    | exit 0, no output   |
| Lint      | `pnpm lint`                 | exit 0              |
| Build     | `pnpm build`                | exit 0; route table shows ƒ only for `/[locale]/[...rest]` |

⚠️ **Before `pnpm build`**: run `lsof -ti :3000 -sTCP:LISTEN`. If a process is
listening, a dev server is running — `next dev` and `next build` share `.next`
and the build corrupts the dev server (gotcha `next-build-clobbers-dev-cache`).
Either get the operator to stop it, or after building: kill it, `rm -rf .next`,
restart `pnpm dev`.

### Step 2: Clean tailwind.config.ts residues

In `tailwind.config.ts`:
1. Delete the `chart: {...}` block (lines 47–53) and the `sidebar: {...}` block
   (lines 54–63) from `theme.extend.colors`. Keep every other color group.
2. Delete the whole `keyframes` block (accordion-down/accordion-up) and the
   whole `animation` block.
3. Change `plugins: [require("tailwindcss-animate")],` to `plugins: [],`.
4. Keep `darkMode`, `content`, `borderRadius` untouched.

**Verify**: `grep -n "radix\|chart\|sidebar\|accordion\|tailwindcss-animate" tailwind.config.ts`
→ zero matches

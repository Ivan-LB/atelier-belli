## Findings considered and rejected

(So nobody re-audits these.)

- **`dangerouslySetInnerHTML` in support-shell.tsx** — all 7 call sites traced;
  HTML comes exclusively from committed `messages/*.json` via `t.raw()`. By
  design (documented convention from PRs #23/#25). Becomes a real finding only
  if translations ever come from outside the repo.
- **Inline theme-init script in not-found.tsx** — static, validated values,
  standard anti-FOUC pattern. Not a finding.
- **"main-app.js is 6.4MB" bundle claim** — measured against a dev-server
  `.next`, not a production build; evidence invalid. The underlying question
  (whole homepage as one Client Component, ~954 lines + all case data) is real
  but needs a production measurement before any RSC-split plan is justified.
  If someone wants it: measure First Load JS via `pnpm build` output first,
  compare against the repo's 150KB landing budget, and only then plan.
- **Splitting `globals.css` (2,865 lines) per route / @layer reorg** — churn
  with MED regression risk and no measured payoff today; revisit only after a
  production CSS-size measurement shows real cost.
- **Splitting the 954-line `page.tsx`** — defensible but not before a test
  baseline exists (003), and even then the single-file case-study architecture
  is a documented, deliberate convention (CLAUDE.md §1). Not planned.
- **`fetchPriority="low"` on modal preview images** — marginal; lazy-loading
  already in place. Not worth a change.
- **`.DS_Store` files** — present on disk, NOT committed (`git ls-files`
  confirms), `.gitignore` covers them. Not a finding.
- **`Secure` attribute on the locale cookie** — deliberately omitted in plan
  004 (Safari drops Secure cookies on `http://localhost`, breaking local-dev
  locale switching). `SameSite=Lax` only.
- **minimatch/lodash/glob/picomatch audit advisories** — transitive via dev
  tooling and the dead deps; re-run `pnpm audit` after 001+002 and only chase
  what survives.
- **`typescript.ignoreBuildErrors` / `eslint.ignoreDuringBuilds` removal** —
  documented decision (CLAUDE.md §3); plan 003's `pnpm verify` is the hard
  gate instead. Revisit only if CI is ever added.
